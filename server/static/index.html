🔓 Luau Deobfuscator

Herramienta educativa para analizar y limpiar scripts Lua/Luau ofuscados. El motor ejecuta el script en una VM real de Luau contra un entorno simulado de Roblox y reconstruye el código legible.

⚠️ Motor no disponible en el servidor — revisa el deploy (falta deobf/bin/luau).
